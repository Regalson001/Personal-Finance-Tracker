# ExpenseAware — Personal Finance Tracker Dashboard

> A modern, responsive, and feature-rich personal finance management dashboard built with HTML5, Tailwind CSS, Vanilla JavaScript, and Chart.js. Designed to help users seamlessly monitor income, track expenses, manage monthly budget caps, and visualize spending habits with professional polish.

![Project Banner Preview](https://images.unsplash.com/photo-1551288049-bebda4e38f71?auto=format&fit=crop&w=1200&q=80)

---

## 🚀 Key Features

* **Real-Time Financial Metrics:** Instantly calculates total net balance, income, expenses, and monthly savings rates.
* **Interactive Data Visualizations:** Dynamic Doughnut chart powered by **Chart.js** breaking down expenses by category.
* **Monthly Budget Caps:** Custom budget progress bars with automatic warning states when spending exceeds predefined limits.
* **Transaction Management:** Fully interactive add-transaction form supporting multiple categories, types, and real-time history updates.
* **Searchable Transaction History:** Instant query filtering across description names and expense categories.
* **Modern Glassmorphic UI:** Built with dark-mode slate aesthetics, translucent panel styling, smooth hover micro-interactions, and custom scrollbars.

---

## 🛠️ Tech Stack

* **Markup:** HTML5 (Semantic Structure)
* **Styling:** Tailwind CSS (Utility classes) + Custom CSS (`styles.css` glassmorphic styling)
* **Visualizations:** Chart.js (Interactive data charts)
* **Icons & Fonts:** FontAwesome 6.4.0 & Plus Jakarta Sans (Google Fonts)
* **State & Logic:** Vanilla JavaScript (Dynamic CRUD, metric calculation, and DOM rendering)
